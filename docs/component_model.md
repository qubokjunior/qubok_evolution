# component model

The editor may be rich and object-like. The runtime may not.

## Component categories

| Component | Compile output | Cost |
|---|---|---|
| core | vitality base, brain base, mutation stability | constant upkeep |
| body cell | mass, health, storage, attachment surfaces | mass, metabolism |
| eye | vision radius, cone, sector channels | sensor upkeep, brain input cost |
| mouth | eat/attack action, bite arc, diet mask, mouth power | action cost |
| leg | land thrust, traction, sprint coefficient | stamina drain, mass |
| fin | water thrust, turn support in water, flow affinity | stamina drain, drag |
| tail | steering power, turn efficiency | stamina drain, drag |
| stomach | max energy, digestion throughput | mass, upkeep |
| armor | defense, impact reduction | mass, drag |
| smell organ | scalar field channels | sensor upkeep |
| lateral line | flow sensing | sensor upkeep |
| pheromone gland | signal emission | emission cost |
| color patch | visual/social/species signal | optional signal cost |

Every useful component must have a cost: mass, drag, metabolism, stamina drain, sensor upkeep, brain cost, or action cost.
