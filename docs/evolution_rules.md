# evolution rules

## Controller order

1. Weighted rule brain.
2. Fixed-topology neural controller.
3. NEAT / rtNEAT research branch.

## Mutation order

1. Simple phenotype parameter mutation.
2. Brain weight mutation.
3. Morphology parameter mutation.
4. Component placement/add/remove mutation only after compiler validation is stable.

## Fitness metrics

- survival time,
- net energy delta,
- food intake,
- kills or harvests,
- offspring count,
- damage avoided,
- distance explored,
- habitat fit,
- diversity retention.
